# Parcial 3

## Intrucciones 

### Clonar Y Descargar

Es necesario clonar el repositorio, se muevase a la rama necesaria que en este caso es assessment-3. Despues de haber clonado simplemente escribir en la terminal "docker compuse up --build" la cual levantara toda la aplicacion e ingrese a http://localhost:5173 entrar en la misma.
